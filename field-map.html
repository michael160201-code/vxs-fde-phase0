FDE Intake Blueprint Specifications

Under the VXS controlled transparency protocol, FDE intake is restricted to macro process parameters. Review the structured field schema below, detailing what we collect, why we collect it, and what we strictly prohibit.

REQUIRED DIAGNOSTIC PARAMETERS Mandatory
Parameter Type Target Scope / Options Diagnostic Purpose
Email Address Email Valid professional contact address. Report routing and verification secure channel.
Your Role Select Founder / Formulator / Consultant / R&D / Other Calibrates report vocabulary and recommendation context.
Product Type Select Functional drink / probiotic drink / powder drink / gummy / bar / other Determines baseline physical state and matrix behavior boundaries.
Current Stage Select Concept / bench / pre-pilot / pilot planned / commercial planned / failed Directly influences diagnostic confidence metrics.
Target Scale Select Bench / under 100L / 100-1000L / 1000-5000L / 5000L+ / unknown Models scaling fluid dynamics and thermodynamic dwell times.

Process Parameters Textarea Temperature range, target pH, target shelf-life, packaging style. Provides physical constraints for thermodynamic and stability drift calculations.
Data Retention Level Checkbox Opt-in to anonymized aggregate pattern logging database. Enables pattern signature deposition for system optimization.
✕ STRICTLY PROHIBITED INTAKE FIELDS

To protect your intellectual property and guarantee legal boundaries, the FDE protocol strictly bans the input of the following items under Phase 0. If any of these parameters are entered into intake forms, they will be scrubbed immediately.

Full proprietary formula
Exact percentage ratios
Supplier identities
Commercial brand names
Contract packager names
Customer list metrics
Proprietary process steps
Unpublished IP patents
# FDE Intake Form Field Map

**Version**: Phase 0 Launch MVP  
**Purpose**: Use this as the field blueprint for the static intake page, Tally, Typeform, or any future form tool.

---

## Required Fields

| Field | Type | Options / Guidance | Why It Matters |
| --- | --- | --- | --- |
| Email | Email | Report delivery only | Required for delivery |
| Role | Select | Founder / Formulator / Consultant / R&D / Other | Helps tune report language |
| Product Type | Select | Functional beverage / probiotic beverage / mushroom or adaptogen drink / powder supplement / gummy / bar / other | Defines initial risk context |
| Current Stage | Select | Concept / bench / pre-pilot / pilot planned / commercial planned / already failed | Determines confidence level |
| Target Scale | Select | Bench / under 100 / 100-1000 / 1000-5000 / 5000+ / unknown | Drives scale-up risk |
| Primary Process | Select | Cold process / hot-fill / fermentation / spray drying / extrusion / high-shear / unknown | Maps to T/B/M layers |
| Main Concern | Long text | User-stated failure concern | Keeps diagnosis grounded |
| Manual Review Consent | Checkbox, required | Must be explicit | Required for trust and accuracy |

---

## Optional Fields

| Field | Type | Guidance |
| --- | --- | --- |
| Ingredient Count Range | Select | 1-5 / 6-10 / 11-20 / 20+ / unknown |
| Sensitive System Flags | Select | Living cultures, heat-sensitive actives, proteins, emulsion, moisture-sensitive actives, multiple |
| Optional Process Parameters | Long text | Temperature range, pH range, target shelf-life, packaging type, process sequence |
| Aggregation Consent | Checkbox, default off | Allows anonymized pattern log retention |
| Public Case Consent | Checkbox, default off | Allows public anonymized case only after separate preview/approval |

---

## Fields Not To Ask For In Phase 0

- Full formula
- Exact ingredient percentages
- Supplier names
- Customer names
- Brand name
- Manufacturing contract details
- Proprietary processing instructions
- Medical or regulatory claims
