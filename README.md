# FDE Phase 0 Launch MVP

This folder contains the minimum launch package for the Formula Diagnostic Engine early validation batch.

Brand / domain baseline:

- Public brand: VXS Industrial Intelligence / VXS
- Primary domain: `vxs.systems`
- FDE URL target: `fde.vxs.systems`
- Intake email target: `diagnostics@vxs.systems`

## What This Is

- Static landing page
- Static intake page
- Data handling page
- Public landing page files only
- Internal prompt kits, SOPs, diagnostic templates, and anonymized pattern logs stay local and are not published to GitHub Pages.

## What This Is Not

- Not a SaaS app
- Not a payment flow
- Not a database-backed product
- Not an automated report engine
- Not a BENENOVO sales funnel

## How To Use

1. Open `index.html` for the public overview.
2. Use `intake.html` for free scan applications.
3. Create the VXS inbox or replace `DELIVERY_EMAIL` in `script.js` if the inbox changes.
4. Keep internal diagnostic documents in the local project folder, outside the public Pages repository.

## Launch Target

First 14 days:

- 3-5 real intake submissions
- 3-5 manual diagnostic briefs
- 3-5 feedback responses
- 1 decision on whether paid validation is justified
